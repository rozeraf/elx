# elx — личный ls-клон на Rust

> Рабочее название: **elx** (explore + ls + x для неизвестного). Можно переименовать.

---

## Идея

Персональный замена `ls`, написанная под себя. Не форк, не патч — отдельный инструмент с нуля, вдохновлённый существующими решениями но без их компромиссов.

**Не цель** — сделать универсальный инструмент для всех. Цель — сделать инструмент который идеально работает для меня.

---

## Почему не eza / lsd

| Проблема | eza | lsd |
|---|---|---|
| Конфиг | Почти нет. Флаги через env, поведение не настраивается | Базовый |
| Git интеграция | Есть, но поверхностная | Нет |
| Игнорирование с glob-паттернами | Минимальное | Нет |
| Дерево | Есть, но без нормального игнорирования | Есть, слабое |
| Кастомизация иконок/цветов | Нет | Частично |

**Главная проблема обоих** — ты либо берёшь что дают, либо форкаешь и тянешь весь груз чужого кода.

## Откуда брать исходники и идеи

### Основные референсы

- **[eza](https://github.com/eza-community/eza)** — архитектура дерева, git интеграция, форматирование колонок. Кодовая база большая, смотреть точечно.
- **[lsd](https://github.com/lsd-rs/lsd)** — таблица иконок/расширений, логика цветов, структура крейтов. Чище чем eza, легче читать.
- **[ls (GNU coreutils)](https://github.com/coreutils/coreutils/blob/master/src/ls.c)** — референс по поведению и edge-кейсам. C, но логика понятна.

### Библиотеки (крейты)

- [`ignore`](https://crates.io/crates/ignore) — glob-паттерны, `.gitignore` семантика, рекурсивный обход. Используется в `ripgrep`.
- [`gix`](https://crates.io/crates/gix) — pure Rust git, readonly операции (статус файлов). Легче чем `git2`.
- [`clap`](https://crates.io/crates/clap) — CLI с derive API.
- [`serde`](https://crates.io/crates/serde) + [`toml`](https://crates.io/crates/toml) — конфиг.
- [`figment`](https://crates.io/crates/figment) — layered конфиг (defaults → файл → env → cli флаги).
- [`unicode-width`](https://crates.io/crates/unicode-width) — правильное выравнивание колонок с unicode.
- [`chrono`](https://crates.io/crates/chrono) — форматирование времени.
- [`users`](https://crates.io/crates/users) — имена пользователей/групп по uid/gid.

## Архитектура MVP

```
elx/
├── src/
│   ├── main.rs          — точка входа, CLI
│   ├── cli.rs           — clap структуры
│   ├── config.rs        — конфиг (figment)
│   ├── fs/
│   │   ├── mod.rs
│   │   ├── entry.rs     — один файл/директория (метаданные)
│   │   └── walker.rs    — обход директории с ignore
│   ├── display/
│   │   ├── mod.rs
│   │   ├── grid.rs      — сетка (дефолтный вид)
│   │   ├── long.rs      — длинный вид (-l)
│   │   └── tree.rs      — дерево
│   ├── theme/
│   │   ├── mod.rs
│   │   ├── icons.rs     — иконки по расширению/типу
│   │   └── colors.rs    — цвета
│   └── git.rs           — git status файлов
├── config/
│   └── default.toml     — дефолтный конфиг
├── Cargo.toml
└── README.md
```

### Поток данных

```
CLI args + config file
        ↓
    Config (figment)
        ↓
    Walker (ignore) → Vec<Entry>
        ↓
    Git status (gix) → обогащаем Entry
        ↓
    Display (grid | long | tree)
        ↓
    stdout
```

## MVP — что входит

### Режимы отображения
- [x] Grid — файлы в несколько колонок (дефолт)
- [x] Long (`-l`) — одна строка на файл с метаданными
- [x] Tree (`-T`) — дерево директорий

### Метаданные в long view
- [x] Права доступа (rwxrwxrwx)
- [x] Владелец и группа
- [x] Размер (human-readable: 1.2M, 340K)
- [x] Дата изменения
- [x] Имя файла с иконкой

### Фильтрация и игнорирование
- [x] Скрытые файлы: скрыты по умолчанию, `-a` показывает
- [x] `.gitignore` уважается по умолчанию (через `ignore`)
- [ ] `--ignore-glob "*.log"` — дополнительные паттерны из CLI
- [ ] `ignore` в конфиге — список паттернов

### Git интеграция
- [ ] Статус файла рядом с именем: `M` modified, `A` added, `?` untracked, `!` ignored
- [ ] Определяется автоматически если директория внутри git репы

### Цвета и иконки
- [x] Иконки по расширению (nerd fonts)
- [x] Цвет по типу файла (директория, симлинк, исполняемый, обычный)
- [x] `--no-icons`, `--no-color` флаги

### Конфиг
- [x] `~/.config/elx/config.toml`
- [x] Все дефолты переопределяемы
- [x] Layered: defaults → файл → env → cli

### Совместимость с ls (todo)
- [x] Флаг `-1` для вывода в одну колонку
- [x] Детекция TTY: отключать цвета/иконки при выводе в пайп
- [x] Секция `[when_not_tty]` в конфиге для управления этим поведением
- [x] Флаг `-F` (`classify`) для индикаторов типа файла

---

## Что не входит в MVP (потом)

- Сортировка (по имени, размеру, дате, расширению)
- Фильтрация по типу (`--only-dirs`, `--only-files`)
- Кастомные темы иконок/цветов через конфиг
- Рекурсивный `-R` режим
- Группировка директорий перед файлами
- Размер директории (du)
- `--hyperlink` — кликабельные пути в терминале
